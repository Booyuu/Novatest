# NovaStudio Homepage

Premium dark corporate homepage for NovaStudio.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Current behavior

NovaOS, Marketplace, and Academy are entry points only. They show a maintenance modal instead of a separate product website.

## Future replacements

The code includes comments for replacing the text logo, product dashboard mockup, future demo video, screenshots, social links, and booking URL.
