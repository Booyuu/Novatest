# NovaStudio Homepage

Premium dark enterprise SaaS-style homepage for NovaStudio, the AI-powered marketing operations company building the AI Marketing Operating System for high-growth businesses.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- lucide-react icons

## Local development

```bash
npm install
npm run dev
```

## Notes for future assets

The current build intentionally uses a clean text logo and abstract dashboard placeholders. Replace the marked placeholder comments in the components when final brand assets, product screenshots, and demo videos are ready.

NovaOS, Marketplace, and Academy are intentionally wired to a maintenance modal until the separate NovaOS product website is ready.
